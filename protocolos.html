Protocolos: el lenguaje de la Web

Los protocolos son reglas que hacen posible que el navegador y el servidor se entiendan, aunque estén en lugares distintos.

HTTP y HTTPS

Seguro has visto el candadito en el navegador. Ese detalle está relacionado con HTTPS y con la seguridad de la conexión.

HTTP

Significa HyperText Transfer Protocol. Permite que el navegador solicite páginas y que el servidor responda con contenido.

Ejemplo: http://ejemplo.com

HTTPS

Significa HyperText Transfer Protocol Secure. Protege la comunicación usando cifrado, por eso es más seguro para contraseñas y datos personales.

Ejemplo: https://github.com

¿Qué pasa cuando escribimos https://?

En realidad pasan varias cosas en pocos segundos: se busca el servidor, se protege la conexión y luego se cargan los archivos de la página.

1

El navegador interpreta la URL

Reconoce que se usará HTTPS porque la dirección comienza con https://.

2

Se consulta el DNS

El dominio se convierte en una dirección IP para encontrar el servidor.

3

Se crea una conexión segura

El navegador y el servidor verifican seguridad mediante certificados y cifrado.

4

Se envía la petición

El navegador solicita la página usando una petición HTTP dentro de la conexión segura.

5

Se muestra el sitio

El navegador recibe HTML, CSS, JavaScript e imágenes, y finalmente dibuja la página.

Comentario personal

HTTPS me parece de lo más importante

Para mí, HTTPS es clave porque usamos la Web para iniciar sesión, comprar, estudiar y enviar información. Sin cifrado, esos datos viajarían con mucho más riesgo.

Conclusión

La Web funciona gracias a varias piezas trabajando juntas: cliente, servidor, DNS, direcciones IP y protocolos. Aunque para el usuario solo parece escribir una dirección, detrás ocurre una comunicación organizada y segura.
