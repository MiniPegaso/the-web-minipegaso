Infraestructura: el viaje de una solicitud

Cuando escribimos una dirección web, no aparece por magia. El navegador se apoya en DNS, direcciones IP, redes y servidores.

Primero aparece el DNS

El DNS es como una agenda de contactos de Internet: usamos un nombre fácil y él ayuda a encontrar la dirección real del servidor.

Nombre de dominio

Los humanos recordamos nombres como github.com o google.com. Es más fácil que memorizar una dirección numérica.

Dirección IP

Las computadoras ubican servidores por medio de direcciones IP. Una IP identifica un equipo o servidor dentro de una red.

Pasos de una solicitud web

Este recorrido está simplificado, pero ayuda a imaginar lo que ocurre cuando entramos a un sitio como GitHub o Google.

1

Escribimos una URL

Por ejemplo: https://github.com

2

El navegador consulta el DNS

El DNS traduce el dominio a una dirección IP para saber dónde está el servidor.

3

Se localiza el servidor

Con la IP encontrada, el navegador ya sabe a qué servidor enviar la solicitud.

4

El servidor responde

El servidor envía los archivos necesarios para construir la página web.

Sabías que...

Una IP no siempre es fácil de recordar

Por eso usamos dominios como github.com. Sería muy incómodo tener que memorizar números para cada página que visitamos.

Ejemplo sencillo

Usuario escribe: github.com

DNS busca la IP del servidor.

El navegador envía la solicitud.

El servidor responde con la página.
